#### 적용 결과 — 34곳 (2026-09-21)

스타일 없이 직접 지정되어 있던 텍스트에 전부 적용했습니다. 램프에 맞추는 과정에서 **19곳의 값이 조정**되었습니다.

**`t1060_13_bold` — 28곳**

| 적용 전 | 건수 | 변화 |
| --- | --- | --- |
| lh 18 / ls 0 | 15 | 없음 |
| lh 18 / ls −0.3 | 7 | letter-spacing → 0 |
| lh AUTO / ls 0 | 3 | line-height 18로 고정 |
| lh 13 / ls −0.3 | 2 | line-height 13 → **18**, letter-spacing → 0 |
| lh 18 / ls −0.5 | 1 | letter-spacing → 0 |

**`t1350_14_medium` — 6곳** (전부 값 변경)

| 적용 전 | 건수 | 변화 |
| --- | --- | --- |
| lh 19 / ls −0.5 | 2 | line-height → 18 |
| lh AUTO / ls −0.5 | 2 | line-height 18로 고정 |
| lh 20 / ls 0 | 1 | line-height → 18, letter-spacing → −0.5 |
| lh 21 / ls −0.3 | 1 | line-height → 18, letter-spacing → −0.5 |

적용 후 파일 전체에 **스타일 없이 13 Bold · 14 Medium을 쓰는 텍스트는 0건**입니다. 대표 노드를 스크린샷으로 확인한 결과 텍스트 잘림이나 레이아웃 깨짐은 없었습니다.

#### 📌 작은 크기 weight 변형에 대한 방침 (2026-10-01)

컴포넌트를 문서화하면서 작은 크기의 Bold · Medium 조합이 반복적으로 발견되었습니다. 이에 대한 방침은 다음과 같습니다.

> **아주 작은 폰트는 예외 케이스로 보고 텍스트 스타일로 관리하지 않습니다.**

| 조합 | 파일 전체 사용 | 상태 |
| --- | --- | --- |
| 13 Bold | 28곳 | ✅ `t1060_13_bold` 신설 |
| 14 Medium | 6곳 | ✅ `t1350_14_medium` 신설 |
| 11 Bold | 21곳 | ❎ **예외 — 등록하지 않음** |
| 11 Medium | 15곳 | ❎ **예외 — 등록하지 않음** |
| 13 Medium | 37곳 | ✅ **`t1360_13_medium` 신설 (2026-10-01)** |

#### 🆕 `t1360_13_medium` 신설 (2026-10-01)

| 항목 | 값 |
| --- | --- |
| 스펙 | 13 / line-height 18 / letter-spacing 0 |
| 번호 근거 | Bold 블록 `t1050`(14) → `t1060`(13) 선례를 따라 Medium 블록 `t1350`(14) → **`t1360`**(13) |
| 값 근거 | 기존 13px 스타일 `b500_13_regular` · `t1060_13_bold`와 동일한 램프(13 → 18) |
| 베리어블 바인딩 | `Font family` · `Font weight` · `Font size` · `Line height` · `Letter spacing` 5개 전부 |

**적용 결과 — 37곳**

| 페이지 | 건수 | 적용 전 | 변화 |
| --- | --- | --- | --- |
| Bubble | 12 | lh **AUTO** / ls 0 | line-height 18로 고정 |
| Foundation | 12 | lh **16** / ls **−0.2** | lh → 18, ls → 0 (폰트 변환 후 적용) |
| Progress Stepper | 9 | lh **16** / ls **−0.3** | lh → 18, ls → 0 |
| Card · Grid List · Grid Scroll · Tab | 각 1 | lh 18 / ls 0 | **변화 없음** |

적용 후 파일 전체에 스타일 없이 Pretendard 13 Medium을 쓰는 텍스트는 **0건**입니다.

## 7. 토큰 적용 현황

**기준일 2026-09-21 · 파일 전체 48개 페이지**

디자인 시스템 파일 전체를 스캔해 토큰 바인딩을 정리했습니다.

| 작업 | 건수 |
| --- | --- |
| 값은 토큰과 같은데 바인딩되지 않았던 속성 → 바인딩 | 2,098 |
| 타 라이브러리 토큰 → Syrup `global` 토큰으로 교체 | 2,112 |
| **합계** | **4,210** |

현재 파일의 `global` 토큰 바인딩은 약 32,850건입니다.

### 적용 기준

- **값이 정확히 일치하는 경우에만** 처리했으므로 시각적 변화가 없습니다.
- 인스턴스 내부 노드는 제외했습니다. 오버라이드를 만들지 않기 위해서이며, 원본 컴포넌트가 정리되었으므로 인스턴스는 자동으로 상속받습니다.
- 텍스트 스타일이 적용된 텍스트의 타이포 속성은 스타일이 관장하므로 노드 단위로 건드리지 않았습니다.
