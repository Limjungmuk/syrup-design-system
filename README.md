## 관리 범위

이 공개 저장소에는 공유용 MD와 저장소 관리 문서만 포함합니다. 디자인 시스템 웹 소스와 웹 제작 MD는 게시하지 않습니다. 제외된 로컬 파일은 삭제하지 않습니다.

공유용 MD를 변경하면 관련 내용과 민감정보 포함 여부를 확인한 뒤 Commit·Push합니다. GitHub 반영과 별도 웹사이트 배포는 서로 독립적입니다.
